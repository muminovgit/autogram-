# Autogram 🚗

Faqat avtomobil ishqibozlari uchun Instagram'ga o'xshash mobil ilova (Expo + React Native, iOS va Android).

## Hozirgi imkoniyatlar
- Lenta: mashina postlari, like, izohlar
- Yangi post: galereyadan rasm, izoh, garajdan mashina tanlash
- Garaj: o'z mashinalaringiz (marka, model, yil, rasm)
- Profil: ism, bio, postlar to'ri

Ma'lumotlar hozircha telefon xotirasida saqlanadi (server keyingi bosqichda).

## Ishga tushirish
```bash
npm install
npx expo start
```
Telefoningizga **Expo Go** ilovasini o'rnating va terminaldagi QR kodni skanerlang.

## Keyingi rejalar
Server va haqiqiy akkauntlar, follow, chat, avto-eventlar xaritasi, mashina sotish bo'limi.
